# Real-Time-Private-LTE-eNodeB-Co-Design-on-Xilinx-Zynq-7010-SoC
Implemented a 3GPP Release 10-compliant LTE EPC and eNodeB using ADALM-PLUTO SDR, Xilinx Zynq-7010 SoC, and srsRAN 4G. Successfully broadcast a stable 5 MHz LTE Band 3 carrier at 1845 MHz, verified by commercial Android UE detection of PLMN 901-70.
